#### **My definition of Big Data**: is data that contains multitudes of information. It can be any type of data from numerical to categorical, and can be interacted in many approaches as long as it can successfully obtain information from it. 

#### ***Data Set of Interest*** : From the listed data sets in the GitHub awesome-datascience the data set that I am interested in is the Data Commons, a data collection site hosted by Google - <a href="https://datacommons.org"> Data Commons </a>.
### I believe that Google driving this collection of data is an opportunity to have access to open source Big Data. Google is a huge tool from being a web browser to a set of applications that provide information from location to language translation. The quantity of diverse data set that Google must have collected may be large enough to allow for a deeper understanding of topics of interest. Additionally, it functions as a host of open source data from other organizations such as Feeding America and Stanford University, allowing for access to more data that can be verified as being collected reliably. #### ***Book of Interest*** : The book I find the most interesting would be the “Real-Time Big Data Analytics: Emerging Architecture” by Mike Barlow published by O’Reily Media Inc. This book focuses on how and why it's important to understand data collection that can be done during a live interaction. For example, data that could be collected via social media twenty-four hours of the day or traffic data that could change suddenly due to an accident. This is considered “real-time” data. I find this book interesting because it gives insight into a key factor that makes data collection so valuable. Being able to understand what is happening second per second helps strengthen the ability to strengthen the prediction of algorithms. This approach also allows the opportunity to detect anomalies such as noise which must be addressed when processing data.
